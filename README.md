**Project Overview**

The IoT Based Eye Blink Controlled Smart Vehicle is an embedded system project designed to improve vehicle safety using an Eye Blink Sensor.

The system uses an ESP8266 as the main controller. The eye blink sensor continuously monitors the driver's eye activity. When a blink is detected, the controller immediately stops the vehicle and activates a buzzer as a warning indication.

When no blink is detected, the vehicle continues to move.

**Main Function**

Blink Detected → Vehicle Stops + Buzzer ON

No Blink → Vehicle Moves + Buzzer OFF

**Objectives**
To develop a smart vehicle using ESP8266.
To detect eye blinking using an eye blink sensor.
To automatically stop the vehicle when a blink is detected.
To provide an audio alert using a buzzer.
To control DC motors using an L298N motor driver.
To demonstrate sensor-based vehicle safety.
To develop an embedded system using ESP8266.
